Example Page

This is an example page meant for showcasing the different rendering settings. By default, the stylesheet in a book defines wether text is bold or italic, but you can also enable text to be bold by default for better readability.

Similarly, normal text is displayed at the default font-size and things such as titles are displayed in a larger font, but this is overridden by the stylesheet of the book. Again, you can change the default font-size to 'large' for better readability.

# Diptyx Enclosure 3D Models

Here, the 3D models of the Diptyx enclosure can be found.

## Components

The components are named as follows:

### FreeCAD files

**Diptyx Enclosure**: Full editable source of the Diptyx enclosure models. Created in FreeCAD 1.2.0dev 20260325.

### 3MF & STEP files

* **left_frame_inner**: Inner part of the left frame
* **right_frame_inner**: Inner part of the right frame
* **left_frame_outer**: Outer part of the left frame
* **right_frame_outer**: Outer part of the right frame
* **left_cover**: Left screen cover
* **right_cover**: Multi-part model of the right screen cover + LED covers
* **power_button**: Power button
* **page_button**: Button for flipping pages (left and right button)
* **knob**: Button that sits over the center joystick

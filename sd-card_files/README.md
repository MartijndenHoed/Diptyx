Welcome to to your Diptyx E-reader!
For the terms and conditions and safety information, refer to the built-in manual and included booklet.

The basic file structure is as follows:
EPUBS are stored in the root of the SD card
YAFF fonts are stored in the fonts folder
Custom idle screens are stored in the root, and are called idle_screen_left.jpg and idle_screen_right.jpg

For more information on the device, guides, and troubleshooting, refer to
https://diptyx.dev/

For information on developing, schematics, and 3d-models, refer to:
